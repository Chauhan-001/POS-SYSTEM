# Phase 4.1: Forecasting Foundation & Data Sufficiency

## Objective
Build the demand forecasting infrastructure with data sufficiency gating. Produce forecasts at restaurant/category/product/variant/time-slot level with confidence intervals, using statistical baselines only (no ML).

## Must-Haves (Goal-Backward Verification)
- [ ] DataSufficiencyClassifier returns INSUFFICIENT_DATA/LOW/MODERATE/HIGH based on historical days
- [ ] ForecastEngine produces predictions with expected_range, confidence, historical_baseline, trend, data_sufficiency
- [ ] Statistical baseline: comparable periods + linear trend + day-of-week + time-of-day + seasonality (HIGH_CONFIDENCE only)
- [ ] Forecast explainability: what/why/history/confidence/what-could-change
- [ ] Forecasts computed in background jobs, cached with TTL, incrementally updated
- [ ] Forecast model version stored with each prediction for evaluation

### Task 3: Create ForecastEngine (Statistical Baselines)
**read_first:**
- backend/src/services/recommendationContext.ts (buildSalesContext - weekdayPerformance, hourlyPerformance)
- backend/src/services/offerEngine.ts (RecommendationContext structure)

**action:**
Create `backend/src/services/forecastService.ts`:
- `ForecastEngine` class with method `generateForecast(restaurantId, branchId, entityType, entityId, timeSlot, horizonDays): Promise<Forecast[]>`
- Algorithm per CONTEXT.md D-02:
  1. Get historical sales for same time_slot across comparable periods (last N weeks, same day-of-week)
  2. Compute linear trend (simple linear regression on daily totals)
  3. Apply day-of-week multiplier (from weekdayPerformance)
  4. Apply time-of-day multiplier (from hourlyPerformance)
  5. If HIGH_CONFIDENCE: add seasonality (compare same month last year)
  6. Calculate expected_range: predicted ± 1.96 * residual_std_dev (or ±20% for LOW/MODERATE)
  7. Set confidence from DataSufficiencyClassifier
  8. Build explainability object: what, why, history_summary, confidence, what_could_change
- Model version: "statistical-v1"
- Cache forecasts: HIGH=1hr, MODERATE=30min, LOW=15min

**acceptance_criteria:**
- `grep -q "generateForecast" backend/src/services/forecastService.ts`
- `grep -q "linear trend" backend/src/services/forecastService.ts`
- `grep -q "day.of.week" backend/src/services/forecastService.ts`
- `grep -q "expected_range" backend/src/services/forecastService.ts`
- `grep -q "explainability" backend/src/services/forecastService.ts`
